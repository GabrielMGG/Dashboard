## Sobre o Projeto

O **Dashboard Admin** é uma interface administrativa desenvolvida com HTML, CSS e JavaScript puro, sem dependência de nenhum framework ou biblioteca externa. O projeto simula um painel de controle real para gestão de usuários, com funcionalidades de busca dinâmica, filtragem por status, paginação e edição de registros via modal nativo.

---

## Funcionalidades

- **Busca em tempo real** por nome de usuário, com atualização instantânea da tabela
- **Filtro por status** — exibe todos, apenas ativos ou apenas inativos
- **Paginação** com navegação por botões (Anterior / Próximo / página direta)
- **Modal de edição** com campos de Nome, Email, Empresa e Status do usuário
- **Badge de status dinâmico** com indicador visual (ativo/inativo)
- **Salvar alterações** diretamente na tabela sem recarregar a página
- **Layout responsivo** adaptado para diferentes resoluções

## Tecnologias Utilizadas

## Como Executar Localmente

Sem dependências. Clone e abra direto no navegador:

```bash
# Clone o repositório
git clone https://github.com/GabrielMGG/Dashboard.git

# Acesse a pasta
cd Dashboard

# Abra o arquivo index.html no navegador
# (ou use Live Server no VS Code para hot reload)
```
